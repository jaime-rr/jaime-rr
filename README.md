## Featured project

### [Facilities & Maintenance Requests](https://github.com/jaime-rr/servicenow-facilities-maintenance)

A ServiceNow scoped application that puts office repair requests on the platform: portal intake,
urgency rules that set priority from the issue category, a €150 spend threshold with manager
approval above it, vendor routing by trade, and form-level policy that keeps the cost estimate with
the agent. Complete, and covered by eleven automated tests.
